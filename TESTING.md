# Win AIO Optimize — validation

Local validation on 2026-10-22: LLVM-MinGW x64 C11 release build passed with `-Wall -Wextra -Werror`. Read-only self-tests report 33 checks and zero failures. Native UI tests pass in English/Vietnamese and Light/Dark. They cover a single top-level app window, embedded pages, close/back without app exit, reopening the same page, navigation blocked during work, Advanced visibility and preserved settings/DNS selections. Filtered adapter tests retain the underlying adapter identity. Failed recovery and Cancel remain unaccepted. No optimizer, DNS, Appx, WiFi import or shutdown action was applied to the development host. MSVC/GitHub Actions and the privileged VM matrix below still require their own acceptance runs.

Executable product/version metadata, strict UTF-8 decoding, PowerShell bootstrapper parsing and manifest XML parsing passed. Imports are Windows system/UCRT DLLs. The local `dist/win_aio_optimize.exe.sha256` matches the rebuilt executable. Installer download/publication has not been tested against a published release.

## Automated, read-only

- Build with C11 and warnings as errors (`build.bat` or CMake).
- Both build paths automatically write a matching `.exe.sha256` file.
- Packaging verifies that all seven embedded icon sizes match `src/icon.ico`, checks Windows Shell icon extraction and requests an Explorer refresh for the output file using [SHChangeNotify](https://learn.microsoft.com/en-us/windows/win32/api/shlobj_core/nf-shlobj_core-shchangenotify). Validation repeats the icon checks without changing the Shell cache. A downloaded or copied EXE may have its own cached Explorer entry.
- Run `powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts\validate.ps1` for the shared local/CI suite. It validates UTF-8, PowerShell syntax, versions, EXE metadata, checksum, self-tests and four UI combinations. Use `-Binary` for CMake output, `-SourceOnly` without an EXE, or `-Inventory` to include a real hardware read. Each executable test has a timeout and saves output/error logs to a unique `build-native/validation-*` folder.
- Run `win_aio_optimize.exe --self-test`; expect exit code 0. This path bypasses UAC and never opens the normal app or changes settings.
- Parse `install.ps1` with the PowerShell parser; do not execute the download on a machine without published matching release assets.
- Run `win_aio_optimize.exe --smoke-test --lang=en` and `--smoke-test --lang=vi`; expect exit code 0. Native diagnostic windows test both translation directions while preserving input and selections, then close. They stay hidden except for an off-screen, non-activating repaint test: Windows discards update regions for hidden windows. Network tests use synthetic adapters; package tests use an allowlisted synthetic row. No DNS configuration or package deployment occurs. This is not proof that privileged operations work.
- CTest runs the self-test and all four language/theme UI combinations, each with a 45-second timeout.
- `--inventory-test` reads real WMI/DXGI/firmware information without UAC or settings changes. It prints only row/error counts. Provider failures or missing firmware permissions may be environment-specific; inspect the UI for the affected category.
- `--preview --lang=en --theme=light` (or `--lang=vi --theme=dark`) opens a read-only dashboard for visual review and closes after 60 seconds. Read-only navigation, Advanced and language/theme selection are interactive; preferences are not saved. Do not use this mode for functional acceptance of system operations.
- `--preview=setup` also opens the grouped Windows Setup page for read-only visual review. Search, scrolling and selection work; protection, optimization and restoration cannot run. The single main window closes after 60 seconds.
- `--preview=network` and `--preview=info` open the respective embedded pages with synthetic adapters or hardware rows. The dashboard also uses sample identifiers in preview mode. These modes allow layout, scrolling and translation review without exposing real hardware identifiers or changing network/system settings.
- UI smoke checks include translated report-column headings, row height against font metrics and column widths at the minimum network/system-information window sizes. These structural checks complement visual review; they do not prove that every pixel renders correctly.

## UI revision verification — 2026-10-22

- Dashboard shows essential computer information, three shortcuts and the timer. Advanced reveals account/build diagnostics and the bounded activity log. The inventory, network and optional-app pages also hide technical detail by default.
- Native report rows have font clearance, fitted columns and custom borderless text/selection painting. A separate heading stays outside the scrolling report client and reads the current column labels/widths.
- Explicit report layout positions the heading and body together without intercepting native window-position messages. Control moves suppress stale pixel copying; parent and children are invalidated after geometry is complete. The native test checks the whole visible repaint region after resizing and a large-to-small adapter refresh.
- Pages share the dashboard's bounded, centered content width. Tests check Back/page alignment at 1040×740, 1180×840 and 1920×1080, plus stable report geometry when columns update.
- The DNS default view prioritizes physical Ethernet/Wi-Fi connections using Windows interface metadata. On virtual-only systems it falls back to a gateway/IP-enabled interface. Advanced retains every adapter. Tests cover refresh from many adapters to one, preserved adapter identity, virtual fallback, and clearing a selection that becomes hidden.
- Read-only previews cover English/Vietnamese and Light/Dark, including minimum-size Setup, network and information pages and a wide dashboard. Preview data is synthetic.
- The LLVM-MinGW C11 build and shared validation suite passed, including 33 self-tests and all four language/theme UI combinations. Existing tests also preserve DNS input, list selections and recovery consent behavior.
- Common-control paint handling honors a supplied device context, as described in [Microsoft's WM_PAINT documentation](https://learn.microsoft.com/en-us/windows/win32/gdi/wm-paint).
- Layout invalidation follows [RedrawWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-redrawwindow); adapter classification uses [MIB_IF_ROW2](https://learn.microsoft.com/en-us/windows/win32/api/netioapi/ns-netioapi-mib_if_row2), including hardware/filter flags.
- This verification does not replace the disposable-VM acceptance matrix below, including privileged changes and 125–200% display scaling.

## Manual acceptance in disposable VM snapshots

Use Windows 10 22H2 and supported Windows 11 builds, including a Home/Pro machine and an Enterprise machine. Record edition/build, result codes, and before/after state. Exercise both UI languages, keyboard navigation, display scaling, cancellation, and error dialogs.

| Area | Check |
| --- | --- |
| Startup | UAC cancellation exits cleanly, a second instance focuses the first, correct effective account shown. |
| Languages | On a fresh account use Windows UI language (Vietnamese, otherwise English). Change the selector, close/reopen, verify the preference persists. Verify `--lang=en`/`--lang=vi` override one launch without rewriting the saved preference. Check DNS text, list selection/checkboxes and timer values survive switching. A busy job or modal confirmation blocks switching. Windows-owned buttons/tool output may follow installed system resources. |
| Consent | All optimization checkboxes start clear; Cancel, Escape, window close, and default Enter leave Windows unchanged. Confirm lists exactly the selected items. |
| Recovery | Both labeled recovery checkboxes start checked at the top of Windows Setup. Opening the page, toggling options, searching and Cancel create nothing. Check all four combinations on apply and restore. Other tools' confirmation dialogs must not offer these options. Denied backup access/disk full/non-ACL storage must stop before the restore step or requested mutation. Disabled System Protection/missing SrClient must stop before mutation after any completed registry backup. Retry or cancel back to Setup to change options; no automatic bypass. Verify SYSTEM/SOFTWARE/HKCU hive files, restrictive inherited ACLs and completion marker. Confirm current-user scope, unique folders and no overwritten earlier backup. |
| Restore points | Enable System Protection in a disposable VM; confirm begin/end returns a valid sequence and point is visible in Windows. Repeat within the configured frequency window and verify honest reuse reporting. Do not silently change frequency or enable protection. Verify no mutation occurs on either API failure. Exercise actual recovery from the VM snapshot rather than replacing development-machine registry hives. |
| Appearance | Windows theme default, app-only Light/Dark choice, persistence after reopen, live Windows light/dark change, High Contrast, keyboard focus and checkbox operation. Inspect the dashboard, embedded feature/review pages and Windows-owned dialogs, combo popups, headers, read-only values and disabled controls at 100%, 125%, 150% and 200% scaling. Windows-owned chrome/dialogs can follow OS styling. |
| Setup layout | Cards reflow between two and three columns without overlap. Search matches English/Vietnamese labels and categories; hidden selected items remain selected and appear in the review. Clear selection clears all optimization choices, including hidden ones, while preserving recovery options. Mouse-wheel, scrollbar dragging and Tab reach every supported setting. Unsupported options stay unchecked and explain their support limit. |
| Language repaint | With Setup open, switch the dashboard language repeatedly in Light/Dark. All pages update, button surfaces have no white remnants, and text wraps inside cards. Repeat after scrolling, searching, resizing and opening combo popups. |
| System information | Essential properties appear first. Advanced reveals the full inventory, category filter and copy/full-value controls. Switching back hides diagnostics without losing selection. Check categories against Windows tools: RAM modules, >4 GiB VRAM, multiple GPUs/disks/adapters, UEFI/Secure Boot and battery/no battery. Verify unavailable values and query errors, category filter, full-value selection, explicit clipboard copy, refresh and read-only behavior. No automatic log/upload of hardware identifiers. Test disabled WMI and slow providers. |
| Navigation | Every app page and review stays inside one main window. Back/Escape/page close returns home and preserves inputs. Only the main title-bar X exits. Repeat with Advanced expanded, language changes, resizing and a busy worker. Tab must reach the sidebar, page controls and appearance selectors. |
| Background work | Window remains repaintable; a second job and application close cannot interrupt a mutation. Canceling an unrelated dialog cannot close a worker's owner. |
| Optimizer | On each supported option inspect the exact registry/service/power state; unsupported edition/build/hardware is reported without false success. |
| Restore | Existing DWORD values and absent values are restored correctly; service startup and power settings restore from their saved values. Corrupt/truncated snapshots fail closed. |
| Search/AI | Verify actual Search, Edge, widgets and AI behavior after sign-out/reboot; do not infer effectiveness from successful registry writes alone. |
| Bloatware | Only listed installed optional packages can be selected; Store/framework/shell packages are absent. Cancel changes nothing; removal checks Windows deployment result. Reinstall test apps before restoring VM snapshot. |
| DNS | Default view shows connected adapters when available; Advanced includes disconnected adapters and IP/MAC details. A selected adapter must never change identity during filtering. Select a disconnected and connected adapter; test both families and providers, one custom server, two servers, malformed addresses, duplicates, DHCP restoration, secondary server failure and adapter removal between selection/application. Record original DNS first. |
| WiFi | No adapter/service stopped, empty profile list, export protected/plaintext XML, denied access, Unicode SSID/path, valid/invalid XML import. Confirm credentials never enter activity.log. |
| Drivers | DISM succeeds to a fresh directory; cancel folder selection, disk full/read-only destination, process failure and reboot-required exit code are reported correctly. |
| Shutdown | Reject zero/negative/overflow/non-numeric input. In a disposable VM only, schedule, reopen, cancel, and reboot to verify persisted state expiry. Check warning about unsaved work. |
| Packaging | Clean build without Python; packaged executable icon/version/manifest present; installer rejects bad checksum and wrong version. |

Actual registry changes, package removal, DNS changes and shutdown are intentionally excluded from automated tests on the developer machine. A successful build/self-test does not replace this VM acceptance pass.
